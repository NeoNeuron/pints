# Paris Île-de-France Neuroscience, Theory, and Systems (PINTS)

The new website for PINTS conference.

Original website: https://pints2025.sciencesconf.org

## Requirements for the new website

- (priority) login system for registered participants and admins, with different rights
- (priority) abstract submission system
- names of registered people
- easy to add/edit schedules, so should better than just an Excel screenshot
- poster list with abstracts
- standalone page can be edit it, better in human-friendly markdown format
- (bonus) mailling list management

## Database services

use the Firebase dataset for login system and data management for user accounts.
The website should be hosted on github page.
